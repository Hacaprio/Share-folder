# 모아 Atelier 디자인

이 앱은 매일 쓰는 작업 도구를 편안하게 찾고 실행하는 공간입니다. 2.1에서는 따뜻한 종이색과 녹색을 중심으로 홈과 공통 작업 화면을 정리했습니다.

## 적용한 방향

- 첫 화면은 이미지 작업실·캔버스·문서 도구를 시각적인 미리보기와 함께 안내합니다.
- 전체 24개 도구는 분류와 검색으로 찾습니다. ‘누끼’, ‘움짤’, ‘문자 추출’ 같은 표현도 검색할 수 있습니다.
- 홈에서 Cmd/Ctrl+K로 검색에 바로 접근합니다. 다른 도구를 열면 홈 검색 단축키를 해제합니다.
- 메뉴는 접을 수 있는 분류로 정리하고, 현재 도구가 속한 분류를 열어 위치를 보여줍니다.
- 폼·버튼·결과·캔버스의 색, 타이포그래피와 간격을 통일합니다. 모바일에서는 내용을 한 열로 배치하고 조작 영역을 넓힙니다.
- 포커스 표시와 동작 줄이기 설정을 지원합니다. 캔버스 첫 클릭의 자동 스크롤도 방지해 포인터 좌표가 어긋나지 않게 했습니다.

## 다른 디자인 방향

| 방향 | 인상 | 적합한 경우 |
| --- | --- | --- |
| Atelier · 적용 | 종이색·녹색, 시각적인 도구 소개와 여백 | 이미지·문서 작업을 함께 쓰는 개인 스튜디오 |
| Workspace · 대안 | 흰색·파란색, 목록과 높은 정보 밀도 | 반복적인 운영 업무와 빠른 도구 탐색 |
| Night Studio · 대안 | 어두운 화면·민트색, 편집 화면 중심 | 디자인·영상 편집에 집중하는 작업 공간 |

## 코드와 자산

- `design.css`: 색상과 공통 화면·반응형 스타일
- `src/home.js`: 홈, 도구 검색과 분류 필터
- `src/suite.js`: 내비게이션과 도구 연결
- `src/icons.js`: 로컬에 포함한 Lucide 아이콘
- `assets/studio-cup.jpg`: 내장 예제에서 생성한 비개인 컵 일러스트

아이콘·미리보기는 외부 요청 없이 표시합니다. 사용자 프로젝트 파일이나 작업 화면 캡처는 디자인 자산에 포함하지 않습니다. 처리 엔진과 프로젝트 파일 형식은 그대로 유지합니다.
