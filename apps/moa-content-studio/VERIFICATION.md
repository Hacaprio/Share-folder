# 검증 및 제한

공유 전 macOS/Chromium에서 다음 검사를 통과했습니다.

| 검사 | 결과 |
| --- | --- |
| 핵심·ZIP·계산·캔버스·확장 단위 검사 | 18개 통과 |
| 로컬 이미지·문서·OCR·영상 엔진 | 29개 통과 |
| 브라우저 회귀 검사 | 18개 통과 |
| 로컬 API·입력 오류·취소 | 7개 통과 |
| 다운로드 파일 디코딩·구조 | 11개 통과 |

1440px·390px 폭에서 각각 26개 화면 진입을 확인했습니다. 즉시 도구 이동 시 마지막 입력 보존, 영상 프레임 선택 시 처리 영역 초기화, 빠른 메뉴 전환을 보완했습니다. QR 실제 인식, ZIP 무결성, Word 문자, PDF 페이지, GIF 프레임과 MP4 재생을 검사했습니다.

화면녹화는 합성 스트림과 실제 MediaRecorder/FFmpeg로 검증했습니다. 전체 PNG/PDF 캡처는 실제 브라우저 명령 출력으로 검사했습니다. 사용자 프로필에서의 확장 설치·실제 공유 선택창·시스템 오디오 권한은 자동 검증하지 않았습니다. 실제 휴대폰·다른 운영체제·모든 대형 파일 조합도 별도 검증이 필요합니다.

브라우저 프로필, 작업 기록, 로컬 화면 캡처, 다운로드 결과, 실행 중 API 응답은 공개하지 않습니다. 공유본에는 재실행 가능한 단위·엔진 검사와 생성한 컵 일러스트만 포함합니다.

## 2.1 디자인 검증

추가 화면·조작 검사 14개가 통과했습니다. 1440·1024·390·320px에서 각각 26개 경로를 확인했고 가로 넘침이 없었습니다. 검색어·분류·검색 초기화·단축키·접이식 메뉴·추천 작업 이동, 실제 QR 다운로드·Word 변환, 캔버스 드래그와 복구, 이미지 3장 일괄 저장을 확인했습니다. 처리되지 않은 JavaScript 오류도 없었습니다. 핵심 단위 테스트 18개도 다시 통과했습니다.

캔버스 첫 클릭 시 포커스로 인한 자동 스크롤을 방지했고, 비대화형 알림이 뒤의 작업 버튼 클릭을 가로막지 않도록 했습니다. 데스크톱과 모바일의 주요 화면은 육안으로도 확인했습니다. 검증 화면 캡처와 실행 결과 파일은 공개 저장소에 포함하지 않습니다.
