# 모아 콘텐츠 스튜디오

사진·문서·영상과 판매 계산을 한곳에서 처리하는 로컬 웹 앱입니다. 24개 도구와 정밀 이미지 편집을 포함합니다. 상태: 사용 가능.

## 설치와 실행

검증 환경은 macOS Apple Silicon / Chromium입니다. Python 3.10 이상, Node.js 18 이상과 npm 또는 pnpm이 필요합니다. 다른 운영체제와 실제 모바일 기기는 별도 검증이 필요합니다. `.command` 실행 파일은 macOS용입니다.

```sh
git clone https://github.com/Hacaprio/Share-folder.git
cd Share-folder/apps/moa-content-studio
python3 setup.py
.venv/bin/python server.py --port 4173
```

브라우저에서 <http://127.0.0.1:4173/#home>을 엽니다. macOS에서는 첫 설치 후 `start.command`로 실행할 수도 있습니다. 서버 터미널에서 Ctrl+C를 누르면 중단합니다. 외부 공개 서버에 배포하는 구성이 아닙니다.

설치 프로그램은 이 폴더의 `.venv`와 `node_modules`에 의존성을 설치합니다. AI/OCR 모델과 한글 폰트는 `models/manifest.json`의 공개 원본에서 받아 SHA-256을 검사합니다. 모델 바이너리와 설치된 환경은 Git에 포함하지 않습니다. 첫 설치에는 네트워크가 필요합니다. 전체 캡처 확장 ZIP은 설치 시 동봉 소스로 생성합니다.

## 입력·출력·보관

파일은 브라우저 또는 이 컴퓨터의 처리 엔진에서 처리하며 외부 서비스로 업로드하지 않습니다. 입력은 사진·영상·PDF·Word·라벨 텍스트·계산 조건이며, 출력은 이미지·문서·GIF/MP4·ZIP 등입니다. 파일 선택이나 다운로드만으로 저장소에 업로드되지는 않습니다.

이미지·캔버스 프로젝트와 일부 입력은 브라우저 IndexedDB에 보관합니다. 변환 결과의 임시 파일은 저장소 밖 시스템 임시 폴더에서 처리하고 약 2시간 또는 정상 종료 시 정리합니다. 필요한 결과와 프로젝트는 다운로드해 별도 보관하세요.

## 선택 환경 변수

API 키·계정 로그인이 필요하지 않습니다. `MOA_NODE`는 OCR에 사용할 Node 실행 파일, `MOA_PDFTOPPM`은 선택적 Poppler 실행 파일 경로를 지정할 때 사용합니다. 지정하지 않으면 사용 가능한 런타임을 찾고 PDFium을 PDF 렌더링 대안으로 사용합니다. 실제 로컬 경로나 비밀값을 저장소에 기록하지 마세요.

## 지원 범위


- 일괄 이미지: 최대 100장·500MB, 한 파일 40MB, 원본 1억 픽셀. 출력 한 변 16,384px·4천만 픽셀 이하. 기준 크기 16~8192px.
- 정밀 편집·AI 도구는 4천만 픽셀 이하 사용을 권장합니다. 로컬 엔진 요청은 합계 200MB·파일 100개까지입니다. 동시 처리 2개·진행/대기 4개로 제한합니다.
- AI 배경 제거는 복잡한 머리카락·유리·투명 물체에서 완벽하지 않습니다. 브러시로 수정하세요.
- 영역 복원은 주변 픽셀을 바탕으로 추정합니다. 가려진 원래 내용을 정확히 복구하는 기능이 아닙니다. 얼굴·밝은 표시 감지는 보조 기능이며 누락·오탐을 수동 확인해야 합니다.
- 캔버스는 최대 10페이지·전체 60초. 영상은 너비 최대 960px·12FPS의 프레임을 만들어 로컬 인코더로 변환합니다. 애니메이션 내보내기 중 레이어 편집을 잠급니다.
- Word 텍스트 변환은 복잡한 서식을 복원하지 않습니다. Word 이미지 방식과 PPT는 페이지 이미지를 배치하며 글자는 편집되지 않습니다.
- Excel은 선으로 구분된 단순 표를 추출합니다. 병합 셀·수식을 복구하지 않습니다. 인식·표 보정 결과는 별도로 저장하세요. OCR 정확도는 원본 품질에 따라 달라집니다.
- PDF 렌더링은 한 번에 최대 60페이지입니다. Poppler가 있으면 사용하고 없으면 PDFium으로 대체합니다.
- A4 템플릿은 일반 격자 25종이며 특정 제조사 규격을 보장하지 않습니다. 실제 용지 여백을 조정하고 **100% 배율로 시험 출력**하세요.
- GIF 구간: 시작 0~10분, 한 구간 최대 60초, 합계 120초, 최대 10개 구간. 영상 영역 복원: 최대 1080p·60초의 고정 영역이며 움직이는 표시를 추적하지 않습니다.
- 화면녹화·화면 캡처는 사용자가 브라우저 공유 선택창에서 허용해야 합니다. 실제 권한 선택창은 자동 검증하지 않았으며 합성 스트림으로 녹화·변환을 통합 검증했습니다.
- 전체 스크롤 캡처는 동봉 확장을 사용자가 설치해야 합니다. 확장 설치·권한 팝업의 실사용 검증은 별도이며, 확장 코드와 실제 Chrome 캡처·PDF 명령의 출력을 검증했습니다. 무한 스크롤은 필요한 내용을 먼저 로딩해야 합니다.
- 수수료 표는 참고 자료이며 자동 갱신하지 않습니다. 실제 적용 요율·시행일·계약 비용을 확인해 입력하세요. 계산 예시는 실제 적용 정책과 구분합니다. 광고비·반품 비용 등은 입력한 항목만 반영하며 세금 신고용 계산기가 아닙니다.

## 검증

```sh
node --test tests/core.test.js tests/zip.test.js tests/fees.test.js tests/capture-extension.test.js tests/canvas-model.test.js
.venv/bin/python tests/full_backend_test.py
```

시험에는 생성한 컵 일러스트만 사용합니다. 엔진 테스트가 이미지·PDF·영상 시험 자료를 생성하며 결과는 Git 제외 폴더 `tests/full/artifacts/`에 기록합니다. 로컬 브라우저 프로필·스크린샷·다운로드 결과·세션 정보는 공유본에 포함하지 않습니다. [검증 및 제한](VERIFICATION.md)을 참고하세요.

## 전체 페이지 캡처

설치 후 앱에서 캡처 확장 ZIP을 받아 압축을 풀고 Chrome/Edge 확장 관리 화면에서 개발자 모드로 해당 폴더를 로드합니다. 캡처할 탭에서 확장 아이콘을 누르세요. 확장 설치·화면 공유 선택·시스템 오디오 권한은 사용자가 직접 허용해야 합니다.
