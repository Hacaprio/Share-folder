# 공유본 보안

이 폴더는 앱 소스와 공개 출처·의존성 명세만 공유합니다. 실제 계정 인증 정보는 필요하지 않습니다.

- 브라우저 쿠키·프로필·세션·Local Storage/IndexedDB 덤프를 커밋하지 않습니다.
- API 키·개인 토큰·비밀번호·인증서·개인키·실제 환경 파일을 커밋하지 않습니다.
- 입력 파일·고객 자료·프로젝트 백업·로그·스크린샷·다운로드 결과·데이터베이스를 커밋하지 않습니다.
- 설치 환경, 모델 다운로드, 생성한 확장 ZIP과 테스트 산출물은 Git에서 제외합니다.
- `.gitignore`만으로 모든 비밀정보가 차단되지는 않습니다. 게시할 파일 목록과 내용을 확인하고 비밀정보 검사를 실행하세요.

로컬 API의 요청 토큰은 실행할 때 생성합니다. 고정된 토큰·실행 중 토큰 값은 소스에 넣지 않습니다. 이 서버는 루프백 전용이며 공용 인터넷 서버용 인증·격리 구성을 제공하지 않습니다.
