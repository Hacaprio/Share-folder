개발 완료 후 다시 확인했습니다

  • 본문·라벨·계산 조건 입력 직후 다른 도구로 이동해도 마지막 값이 저장되도록 보완했습니다.
  • 영상의 새 프레임을 선택하면 이전 처리 영역을 초기화합니다.
  • 빠른 메뉴 이동과 잘못된 URL, 프로젝트 사진 불러오기 오류 처리를 보완했습니다.

기존 앱 탭을 새로고침하면 수정본이 적용됩니다. 상세 기록은 소스 폴더의 VERIFICATION.md에 있습니다. 실제 화면 공유 권한·확장 설치·다른 기기의 실사용 검증 범위는 아래 지원 조건을 참고하세요.

편집 프로젝트를 복구합니다

이미지 작업실은 원본·설정을, 캔버스는 페이지·레이어·원본을 보관합니다. 새로고침 복구와 프로젝트 파일 저장·재불러오기를 검증했습니다. 캔버스는 PNG/JPG/WebP·ZIP·긴 이미지·PDF·애니메이션 GIF/MP4를 지원합니다.

실제 파일로 검증한 결과

  • 이미지: 배경 알파, 선택 영역 복원·모자이크, 분할 후 원본 픽셀 재조합, QR 디코딩.
  • 문서: PDF 페이지 수·순서·회전, Word·Excel·PPT 구조, 한글 라벨·PDF 서명 렌더링, OCR 문자와 수정 파일.
  • 영상: 여러 구간 GIF, 복원 MP4, 화면녹화 스트림의 MP4 변환, 캔버스 애니메이션 960×540·12프레임.
  • 계산: 스마트스토어·지마켓·옥션·11번가·쿠팡·로켓그로스 예제와 원 단위 처리, 쿠폰 상계·월 비용.
  • 화면: 데스크톱 및 390px 폭에서 전체 메뉴 진입·가로 넘침 검사. 실제 휴대폰 테스트는 별도입니다.

지원 조건과 품질 한계

  • AI 배경 제거와 영역 복원은 결과 확인·수동 보정이 필요합니다. 가려진 원래 내용을 정확히 되찾는 기능은 아닙니다.
  • Word 텍스트는 복잡한 서식을 재현하지 않습니다. 이미지 Word·PPT의 글자는 편집되지 않습니다. Excel은 단순 표 추출입니다.
  • 영상 복원은 1080p·60초의 고정 영역을 지원합니다. 움직이는 표시 추적은 포함하지 않습니다.
  • 라벨 25종은 일반 A4 격자입니다. 실제 제품 여백·간격에 맞춰 100% 시험 출력하세요.
  • 판매 수수료 표는 참고 자료입니다. 실제 계약 요율과 시행일을 확인해 입력하도록 구성했습니다.
  • 변환 임시 파일은 약 2시간 또는 정상 종료 시 정리됩니다. 중요한 결과·프로젝트는 다운로드해 보관하세요.

실행과 유지 관리

현재 로컬 서버에서 실행할 수 있습니다. 다시 시작할 때는 앱 폴더의 start.command를 실행합니다. 다른 컴퓨터로 옮긴 경우 setup.command로 전용 환경을 설치한 뒤 시작합니다. Python 3.10 이상·Node.js 18 이상이 필요합니다.

사용 안내는 README.md, 상세 검증 기록은 VERIFICATION.md, 구현 코드는 src/와 backend/에 있습니다. 설치 스크립트의 잠금 파일·모델 해시와 기존 이미지 작업실 회귀도 확인했습니다.
