# 모아 전체 페이지 캡처 확장

1. Chrome/Edge의 확장 관리 화면에서 개발자 모드를 켭니다.
2. ‘압축 해제된 확장 프로그램 로드’를 선택하고 이 폴더를 지정합니다.
3. 캡처할 일반 웹페이지로 이동한 뒤 확장 아이콘을 누릅니다.
4. PNG 또는 PDF를 선택하고 저장합니다.

현재 탭에 Chrome Debugger Protocol을 잠시 연결해 전체 캡처한 후 해제합니다. 브라우저의 디버깅 알림이 나타날 수 있습니다. 외부 서버 전송·분석·계정 로그인은 없습니다. 긴 페이지는 PDF를 사용하세요. 무한 스크롤이나 아직 로딩하지 않은 콘텐츠는 페이지에서 먼저 로딩해야 합니다. 브라우저 설정·스토어 페이지와 보호된 콘텐츠는 지원하지 않습니다.
