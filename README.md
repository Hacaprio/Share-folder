# Share-folder

앱과 자동화 프로젝트를 모아 공유하는 공개 저장소입니다.

## 공유 및 수정 권한

- 누구나 저장소를 읽고 다운로드하거나 clone할 수 있습니다.
- 이 원본 저장소에는 소유자만 직접 변경 사항을 게시합니다. 다른 사용자에게 쓰기 권한을 부여하지 않습니다.
- 공개 저장소이므로 GitHub의 Fork 기능으로 개인 복사본을 만드는 것은 가능합니다.
- GitHub 접근 권한과 저작물 이용 조건은 별개입니다. 현재 별도의 오픈소스 라이선스를 부여하지 않았습니다. 재배포·상업적 이용 등은 소유자에게 별도로 확인하세요.

## 폴더 구성

```text
app/           모아 콘텐츠 스튜디오
apps/          기타 앱 프로젝트
automations/   자동화 프로젝트
docs/          등록·실행·운영 안내
templates/     새 프로젝트 문서 및 설정 예제
```

이 저장소는 하위 폴더를 함께 관리합니다. 하위 폴더에서 별도로 git init을 실행하지 마세요.
공유 대상이나 공개 범위를 분리해야 하는 프로젝트는 별도 저장소로 만들고 이곳에 링크만 등록합니다.

## 내려받기

```sh
git clone https://github.com/Hacaprio/Share-folder.git
cd Share-folder
```

이후 업데이트는 저장소 폴더에서 `git pull --ff-only`로 받습니다.
각 프로젝트의 설치·실행 방법은 해당 폴더의 README를 따릅니다.

## 프로젝트 등록

[등록 및 운영 안내](docs/project-guide.md)를 따라 프로젝트를 추가하세요.
[프로젝트 템플릿](templates/project/README.md)을 복사해 설치 방법, 실행 명령, 필요한 환경을 작성합니다.
실제 API 키·비밀번호·개인 데이터는 올리지 않습니다.

자동화 코드를 내려받는 것만으로 예약 실행이 설정되지는 않습니다.
실행할 컴퓨터나 서버에서 별도로 설정해야 합니다.
